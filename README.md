# Clasificaci-n-de-AHD
Comparar dos modelos clasificatorios para predecir la variable AHD a partir de un conjunto de datos clínicos, utilizando todas las variables disponibles excepto fbs y ExAng. Se busca implementar correctamente los modelos, evaluar su desempeño mediante una validación simple (división entrenamiento–prueba) e interpretar las métricas de clasificación.
